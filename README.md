I'm a passionate student developer currently studying at the **Khon Kaen University Demonstration School (Satit KKU)**, proudly part of the **SCiUS KKU** (Science Classrooms in University-Affiliated School) program in Thailand. I love building scalable web applications, automating complex workflows, and exploring the intersection of software and hardware.

## 🚀 What I'm up to
- 🔭 **Currently working on:** Expanding [Dewey's World](https://deweysworld.app/), developing YoungJoi, and building web portals for SCiUS student activities.
- 🌱 **Currently exploring:** Physical agentic AI, industrial robotics (Techman Robot / TMflow), and API integrations that connect web apps with hardware.
- 🤖 **Automation:** Bridging AI logic with local servers and hardware using n8n and Node-RED.
